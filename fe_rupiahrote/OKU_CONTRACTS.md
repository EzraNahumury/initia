# Oku Trade — Deployed Contracts Reference

On-chain contract addresses used by Oku Trade for swaps across all chains.

## Key Contracts (per chain)

| Contract | Purpose |
|----------|---------|
| v3 Core Factory | Creates Uniswap V3 pools |
| Universal Router | Multi-action swap routing |
| Swap Router 02 | Token swap execution |
| Quoter V2 | On-chain quote simulation |
| Permit2 | Gasless token approvals |
| Nonfungible Position Manager | LP position NFTs |
| Limit Order Registry | On-chain limit orders |
| Multicall2/3 | Batch read calls |
